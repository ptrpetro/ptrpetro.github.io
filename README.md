# Peter Petro — Portfolio

**Live site:** [ptrpetro.github.io](https://ptrpetro.github.io)

My personal portfolio - a single-page site covering who I am, what I've built,
and what I'm looking for next. Built from scratch with plain HTML, CSS, and
JavaScript, no frameworks or build step required.

## Features

- Typewriter hero intro with a blinking cursor
- Dark / light theme toggle
- Command palette (`⌘K` / `Ctrl+K` / `/`) for quick navigation
- Filterable, expandable project cards
- Subtle 3D tilt on hover for cards
- One-time terminal "boot sequence" on first visit
- Fully responsive, no dependencies

## Tech

Just HTML, CSS, and vanilla JavaScript. No React, no Node, no build pipeline —
what you see in `index.html` is exactly what ships.

## Running locally

```bash
git clone https://github.com/ptrpetro/ptrpetro.github.io.git
cd ptrpetro.github.io
open index.html
```

Or serve it locally for the full experience:

```bash
python3 -m http.server
```

then visit `http://localhost:8000`.
